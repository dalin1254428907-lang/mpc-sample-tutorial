## 后面板接口

| 接口 | 用途 |
|---|---|
| USB-C 接口 | 供电并给内置电池充电（建议用附带线、至少 5V/2A 电源）；连电脑或手机可收发音频和 MIDI，并读写 microSD 卡里的文件 |
| REC GAIN 旋钮 | 调整后面板 AUDIO IN 的录音电平 |
| AUDIO IN 1/L、2/R（6.35mm TRS） | 接麦克风、乐器或线路电平音源（调音台、合成器、鼓机等），用来采样 |
| AUDIO OUT（6.35mm TRS ×2） | 接音箱、调音台等；音量由 MAIN VOLUME 控制 |
| MIDI IN / OUT（3.5mm TRS，Type A） | 用 3.5mm TRS 转 5 针 MIDI DIN 线连接鼓机、合成器等外部 MIDI 设备 |
| SYNC OUT（3.5mm TS） | 5V CV 时钟脉冲输出，用来同步外部模块合成器 |
| PHONES（3.5mm TRS） | 接耳机监听；插上耳机后内置扬声器自动关闭 |

另：POWER 按钮开关机；microSD 卡槽在机身左侧（不在后面板）。
