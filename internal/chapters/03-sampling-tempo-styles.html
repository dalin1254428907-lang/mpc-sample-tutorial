3.3 编辑：把一段采样改造成能用的素材

所有编辑都在 Sample 模式里做。先认一下这个屏幕：

新概念 ① Sample 模式的“页”

Sample 模式下屏幕底部有三个参数，对应 K1 K2 K3 三个旋钮。换一页，三个旋钮的功能就跟着换：

  • 按 B1 依次切换：Trim（剪长度）→ Mix（音量/声像）→ Amp Env（包络）……
  • 按 B2 依次切换：Tune（音高 + Warp）→ Play（播放方式）……
  • 屏幕左上角/参数栏的页名告诉你现在在哪一页（具体位置见上图编号）。

记法： 永远先看屏幕底部三个参数名，再转旋钮。

3.3a Trim：剪掉头尾的空白

新概念 ② 起点 / 终点（Start / End）

采样从哪里开始响、到哪里停。只是“标记”，原声音还在；按 TRIM SAMPLE 才会真的剪掉。

动手 3-1 · 设起点和终点

  • 目标： 让垫子一按就响，不要前面半秒空白。
  • 要按什么：
    1. 按 SAMPLE（29），再敲放着采样的垫子。 屏幕上会出现什么： 这个垫的波形、采样名，底部三个参数 Start / End / Loop（如果不是，按 B1 直到出现 Trim）。
    2. 转 K1（Start）向右。 屏幕上会出现什么： 波形上的起点竖线往右移，K1 下方的百分比（0–100%）变大；左边被跳过的部分（推断）显示为变暗。
    3. 转 K2（End）向左，把尾巴的空白去掉。 屏幕上会出现什么： 终点竖线左移。
    4. 对不准就按住 SHIFT 再转 K1 / K2（Zoom: Start / Zoom: End）。 屏幕上会出现什么： 波形以起点/终点为中心放大，竖线附近的细节看得清。
    5. 敲垫子试听。
  • 你会听到： 只播 Start 到 End 之间。
  • 常见错误： 转了旋钮数值不动——手册说看参数名旁边的箭头，往箭头方向转，直到“接上”当前值。

动手 3-2 · 真的剪掉（TRIM SAMPLE）

  • 要按什么： 按住 SHIFT + PAD 13（TRIM SAMPLE）。
  • 屏幕上会出现什么： 波形重画，起点/终点之外的部分消失，Start 回到 0%、End 回到 100%（推断）。
  • 下一步： 这一步会丢弃头尾音频。想留原版，先 保存一份。

K3 Loop：同一页的 K3 是循环点（采样设为 Loop 播放时从这里回绕），SHIFT+K3 放大循环点。SHIFT+B1 Loop Lock 把循环点锁在起点。

3.3b Normalize：把音量拉满

动手 3-3 · 标准化

  • 目标： 录得太小声的采样，一键拉到合适音量。
  • 要按什么： 在 Sample 模式里，按住 SHIFT + B2（Normalize）。
  • 屏幕上会出现什么： 按住 SHIFT 时 B2 上方的标签变成 Normalize；按下后波形整体变高，最高的峰刚好碰到顶（0 dB）。
  • 注意： 只处理 Start 到 End 之间的部分——所以先 Trim 再 Normalize。
  • 常见错误： 底噪也会一起变大。录音时尽量录大声一点，Normalize 只是补救。

3.3c Chop：把一段采样切成 16 块，用垫子重新“说话”

新概念 ③ 切片（Chop / Slice）

把一段采样切成几小块（slice），每块自动放到一个垫子上。以前按一个垫子，整段 loop 从头播到尾；切完之后，垫 1 是第 1 块、垫 2 是第 2 块…… 你可以打乱顺序、重复某块、跳过某块——同一段素材就变成新的旋律。最多 16 块。

手册举例：采样被切成 8 块时，按 垫 5 就选中第 5 块。

动手 3-4 · 第 1 步：进入 Chop 模式

  • 要按什么： SAMPLE（29）→ 敲放着采样的垫子 → CHOP（33）。
  • 屏幕上会出现什么：
    • 波形上出现多条竖线 = 切点。默认切法是 Threshold（按音量自动切），所以一进来就已经切好了。
    • 底部三个旋钮的功能变了，Trim 被换成 Chop：
旋钮 功能 按住 SHIFT 时
K1 Start 当前这一块的起点 Zoom: Start 放大起点附近
K2 End 当前这一块的终点 Zoom: End 放大终点附近
K3 Chop Type 切法（见下一步） Threshold 灵敏度 0–100%
  • 16 个垫子对应 16 块：亮着的垫子 = 有切片。

动手 3-5 · 第 2 步：选一种切法（转 K3）

切法 怎么切 适合 新手建议
Threshold 按音量起伏自动放切点 鼓 break、一下一下很清楚的钢琴/吉他 SHIFT+K3 往高调 = 切得少；往低 = 切得多
Regions 4 / 8 / 16 平均分成 4、8、16 块 已卡准小节的 loop 1 小节 loop 选 16 = 每块一个 16 分音符
Manual 你边听边拍出切点 人声、弦乐等没有明显起伏的素材 按垫 1 开始播放并放第一个切点，听到想切处就拍下一个垫
  • 屏幕上会出现什么： K3 下方的名字跟着变；竖线重新排布（Regions 是等距的，Threshold 落在音头上）；亮着的垫子数量随块数变化。
  • 💡 先试 Threshold；乱就换 Regions；只要“那一句”就用 Manual。

动手 3-6 · 第 3 步：修切片（每一块都要听）

敲一个垫子 = 选中那一块（屏幕上这块被高亮，推断），然后：

  • K1 / K2 微调这块起止点；对不准就 SHIFT+K1 / SHIFT+K2 放大。屏幕： 被选块两边的竖线移动。
  • SHIFT + B1 = Extract：把这块导出成新采样，放到下一个空垫。不破坏原采样。屏幕： 按住 SHIFT 时 B1 标签显示 Extract（推断）；之后那个空垫会亮起。
  • SHIFT + B2 = Split：这块一分为二，后面编号都 +1。屏幕： 这块中间多一条竖线。
  • SHIFT + B3 = Merge：这块并进前一块，后面编号都 −1（8 块里合并第 2 块 → 剩 7 块，原第 3 块变成第 2 块）。屏幕： 少一条竖线。
  • 按住 ERASE（23）+ 敲垫子：删掉这个切点（同样并进前一块）。

⚠️ 两个坑（手册原文）：

  1. 只要你动手改了切片，K3 的 Chop Type 会自动变成 Manual——屏幕上看到 Manual 别慌。
  2. 改切片不能用 UNDO 撤销。大改前先 SHIFT+B1 Extract 把好用的块存一份。

动手 3-7 · 第 4 步：决定垫子怎么“发声”

  • 默认是 One Shot：敲一下，这块完整播完。
  • SHIFT + CHOP（33）= Note On：按住才响，松手就停。
  • 屏幕上会出现什么： 采样名旁边出现音符图标。Amp Env 页里 K2 的名字从 Decay 变成 Release。
  • 用途： 切人声、长和弦时，靠按的长短控制每块长度，打起来像在“弹”采样。

动手 3-8 · 第 5 步：退出

  • 要按什么： 再按一次 CHOP（33）。
  • 屏幕上会出现什么： 底部参数变回 Start / End / Loop（Trim 页）。切片还在，垫子照样能弹。

边录边切（彩蛋）：在 SAMPLE RECORD（37）录音时，手册写明可以一边录一边敲其他垫子来切。错过好段落：SHIFT + SAMPLE RECORD = RECALL，取回当前输入源最近 25 秒，放到下一个空垫。

3.3d Warp：让采样跟上你的速度

新概念 ④ Warp（变速）的两种模式

  • Time Stretch：变长/变短，音高不变（像倍速看视频但声音不变调）。
  • Pitch：变长/变短，音高跟着变（像黑胶转速调慢——慢了也低了）。这是老派 hip-hop“放慢唱片”的声音。

Warp 值：Off（不变）· 50–200%（50% = 一半长 = 快一倍；200% = 两倍长 = 慢一倍）· Seq（锁定当前序列速度）。

动手 3-9 · 把一段 loop 锁到序列速度

  • 目标： 别人 98 BPM 的 loop，放进你 90 BPM 的 beat 也对拍。
  • 要按什么：
    1. SAMPLE → 敲 loop 所在的垫 → 按 B2 直到页名是 Tune。 屏幕上会出现什么： 底部三个参数 Semi Tune / Fine Tune / Warp。
    2. 按住 SHIFT 转 K3（# Beats），设成这段 loop 的拍数（1 小节 4/4 = 4，2 小节 = 8）。 屏幕上会出现什么： K3 位置显示 # Beats 和数字。机器用“长度 ÷ 拍数”判断原速度。
    3. 松开 SHIFT，转 K3（Warp）到 Seq。 屏幕上会出现什么： K3 显示 Seq。
    4. SHIFT + PAD 15（WARP）在 Time Stretch / Pitch 之间切换。 屏幕上会出现什么： 模式名切换（推断：显示在参数栏或弹出提示）；切到 Pitch 时 Semi Tune / Fine Tune 变灰不可用（手册：Pitch 模式下这两项不可用）。
  • 你会听到： 和序列一起播时 loop 对拍。Time Stretch 不变调；Pitch 会随速度升降调。
  • 常见错误： # Beats 设错，loop 会快一倍或慢一倍——数一下原 loop 有几拍。Time Stretch 拉得太多会有“颗粒/金属”声（推断，一般时间拉伸算法的通病）。

想要 Dilla / 日系 jazzy 那种“放慢采样”的味道：Warp 模式选 Pitch，Warp 值设 110–130%（推断的起点值，靠耳朵定）。见 风格页 · Dilla 式。

3.3e 16 LEVELS：一个声音铺满 16 个垫

新概念 ⑤ 16 LEVELS

把当前选中的采样复制到全部 16 个垫，每个垫的某个参数逐级变化。三种 TYPE：

TYPE 16 个垫怎么变 用来做什么
Velocity 力度从小到大 精确打出轻重不同的 hat / ghost snare
Filter 垫 1–8：截止频率从最低升到当前 Cutoff；垫 9–16：从当前值升到最高 闷 → 亮 的扫频感
Tune 垫 4 = 原音高，往下的垫降调、往上的垫升调 用一个 808 / 贝斯音弹 bass line

动手 3-10 · 用 Tune 弹一条 bass

  • 要按什么：
    1. SAMPLE → 敲一个贝斯 / 808 采样的垫（选中它）。
    2. 按 16 LEVELS（36）。 屏幕上会出现什么： Sample 页出现 “16” 图标，表示 16 Levels 已开启；16 个垫现在都是这个声音。
    3. 按住 SHIFT + 16 LEVELS，多按几次切到 Tune。 屏幕上会出现什么： 每按一次，TYPE 在 Velocity / Filter / Tune 之间轮换（推断：屏幕弹出当前 TYPE 名）。
    4. 从垫 1 敲到垫 16。
  • 你会听到： 垫 4 是原音，垫 1–3 更低，垫 5–16 越来越高（推断：每垫一个半音）。
  • 下一步： 按 SEQ（30）→ SEQ RECORD（38），用这些垫弹 bass 录进序列。
  • 退出： 再按一次 16 LEVELS，“16” 图标消失，垫子恢复原来的声音。
  • 常见错误： 在 Sequence 模式里按 16 LEVELS 没反应——手册说明 Sequence 模式下不能用 Chop 和 16 Levels，先回 Sample 模式。Filter TYPE 范围小时，先去 Filter 页调 Cutoff。
  • 实战： 用 16 LEVELS 弹 bass、和弦、人声 hook 的完整例子见 节奏网格实验室（6 条视频，各有音名 → 垫号表）。

3.3f Resample：把整段序列录成一个采样

新概念 ⑥ 重采样（Resample）

把机器自己放出来的声音（多个垫 + 效果）录成一个新采样，放到一个垫上。好处：腾出垫子；效果“烧”进声音里；还可以再切、再 Warp。第一章 1.11 提过一次，这里实战。

动手 3-11 · 方法 A：一键 Resample 当前序列

  • 要按什么：
    1. 先确认序列能正常播放（PLAY 听一遍，再 STOP）。
    2. 按住 SHIFT + PAD 11（RESAMPLE）。 屏幕上会出现什么： 提示你选一个垫（推断：文字类似“Select pad”）。
    3. 敲一个空垫。 屏幕上会出现什么： 序列被渲染成音频（推断：短暂处理提示），完成后那个垫亮起，Sample 页能看到一整段新波形。
  • 你会听到： 敲这个垫 = 整个序列的声音。
  • 常见错误： 选了有声音的垫会被替换（推断）——选空垫最稳。

动手 3-12 · 方法 B：用 SAMPLE RECORD 录“机器自己”

  • 要按什么： SAMPLE RECORD（37）→ 转 K1 把 Source 选 Resample → 转 K2 选 Seq（按序列长度录）或 Free → 敲空垫开录，然后弹/播放。
  • 屏幕上会出现什么： K1 显示 Resample；K2 显示 Seq/Free；录音中电平表跳动。选 Seq 且正在播放时，从当前循环结束处开始录（手册原文）。
  • 适合： 边玩 PAD FX / KNOB FX 边录，把即兴效果固定下来。

3.3g 保存采样

新概念 ⑦ 保存采样 ≠ 保存工程

保存工程（SHIFT + PAD 16，见 1.13）存的是整套东西；保存采样是把一个垫上的声音单独存成文件，以后别的工程也能用 SAMPLE SELECT 载入。

动手 3-13 · 给采样起名并保存

  • 要按什么：
    1. 选中要存的垫，按住 SHIFT + SAMPLE SELECT（SAVE SAMPLE）。 屏幕上会出现什么： 起名页，显示当前名字和光标。
    2. 转 ENCODER 选字母，按 ENCODER 确认并跳到下一位；按住 SHIFT = 大写；−/+ 移动光标；B2 删一个字，SHIFT+B2 全删。 屏幕上会出现什么： 名字逐字变化，光标移动。
    3. 按 B3（Do It!）保存；不想存按 B1（Cancel）。 屏幕上会出现什么： 回到之前的页面（推断：可能有“已保存”提示）。
  • 以后怎么找： SAMPLE SELECT 打开浏览器，B2 切换内部 / microSD；microSD 默认目录 MPC-Sample/Samples。
  • 起名建议： 90bpm-rhodes-chop1——速度 + 素材 + 用途。

3.3 本节小结

  • Trim 设起止点，SHIFT+PAD 13 真剪；Normalize = SHIFT+B2，只处理起止点之间。
  • CHOP（33）切片：K3 选切法，SHIFT+B1/B2/B3 = Extract / Split / Merge；改切片不能 UNDO。
  • Warp 在 Tune 页 K3：Seq 锁速度；SHIFT+PAD 15 切 Time Stretch / Pitch。
  • 16 LEVELS（36）：Velocity / Filter / Tune，Tune 原音高在垫 4。
  • Resample：SHIFT+PAD 11 → 敲空垫。保存采样：SHIFT+SAMPLE SELECT → B3 Do It!

练习 3.3-A：一段 loop 切出新旋律（20 分钟）

  1. 准备一段 1 小节、已对齐拍子的乐器 loop（钢琴/电钢最好）。
  2. SAMPLE（29）→ 选中垫子 → CHOP（33）→ K3 选 Regions 8。屏幕： 8 条等距的块，垫 1–8 亮。
  3. 依次敲垫 1–8，确认每块是“一个音或一个和弦”。切在音中间的块用 K1/K2 调。
  4. SEQ（30）→ SEQ RECORD（38），按新顺序打 1 小节：1 · 1 3 | 5 · 4 · | 1 · 1 3 | 7 · 8 ·（数字 = 垫号，· = 空一个 8 分）。
  5. 加上鼓（参考 风格页 · Boom bap 网格），和原 loop 比，是不是已经“不是同一首歌”了？

练习 3.3-B：Manual 切一句人声（15 分钟）

  1. 选一段人声或说话录音（可用内置麦克风自己录一句）。
  2. CHOP（33）→ K3 选 Manual → 按垫 1开始，在每个字开头依次拍垫 2、3、4……
  3. SHIFT+CHOP 开 Note On（屏幕出现音符图标），用按住时长控制每个字的长短，打一个 2 小节人声 hook。

练习 3.3-C：Warp + 16 LEVELS + Resample 串起来（25 分钟）

  1. 把 3.3-A 的 loop 用 Warp=Seq 锁到 90 BPM。
  2. 一个 808 用 16 LEVELS Tune 弹 2 小节 bass。
  3. SHIFT+PAD 11 把整段 Resample 到空垫，再 CHOP 成 Regions 8 重新排一次——“采样的采样”。
  4. SHIFT+SAMPLE SELECT 存成 90bpm-ex33c。

自查清单

  • 每一块都单独听过，没有切在音的中间
  • 出现“咔嗒”时，K1 往后挪一点或 SHIFT+K1 放大对准
  • 重要的块已经 SHIFT+B1 Extract 备份（改切片不能 UNDO）
  • 知道自己用的是 One Shot 还是 Note On
  • Warp 的 # Beats 设对了，loop 跟序列不跑拍
  • 会用 16 LEVELS Tune 弹 bass，知道原音高在垫 4
  • Resample 后的新采样已保存并起了带 BPM 的名字
  • 新排列和原曲明显不同（3.1 版权自查的一步）
